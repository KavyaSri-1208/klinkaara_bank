# Klinkaara Bank

A Java Web Application (JSP/Servlet) for Klinkaara Bank with modules for:
- 💳 Debit Cards
- 💳 Credit Cards
- 🏦 Loans

## Tech Stack
- Java 17
- Jakarta Servlet 5.0
- JSP + JSTL
- Maven
- Tomcat 10

## Run Locally
```bash
mvn clean package
# Deploy target/klinkaara-bank.war to Tomcat 10
